# 更新日志

本项目遵循[语义化版本](https://semver.org/lang/zh-CN/)。

## [未发布]

### 性能

- 音质探测并发化：网易云各档改用克隆会话并发请求，缩短详情窗「检测可用音质」等待（QQ 走单线程事件循环，仍保持串行）
- 搜索「加载更多」追加时不再每次重建整表去重集合，改为按列表持久化已载入歌曲标识集合
- 列表滚动预加载判断改用内存状态，不再每次滚动读取按钮控件属性
- 「下载选中」不再全表扫描：改为按行标识集合直接取勾选歌曲（勾选 / 全选 / 排序后均增量重建集合）

### 修复

- 下载选项窗切换音质预览会临时改写列表「大小≈」列；取消 / 关闭窗口时按当前配置音质回滚，避免显示与配置不一致
- 主线程消息分派增加异常隔离：单条消息处理出错不再中断消息队列轮询
- 封面下载校验 HTTP 状态，避免错误页被当作封面写入标签；详情窗封面请求补上 `User-Agent`
- 音频标签封面 MIME 按图片真实格式写出（PNG 封面不再被错误标为 JPEG）
- 扫码图片与关窗回调增加窗口存在性校验，避免关窗后后台投递触发界面异常

### 新增

**Web 版（本地服务 + 浏览器前端）**
- 新增 Web 版入口 `MusicDownloaderWeb.py`：本地 HTTP 服务（固定监听 127.0.0.1，不对外暴露）托管静态前端，另开桌面窗口展示服务状态与实时日志，关窗最小化到系统托盘，托盘可重开窗口 / 打开网页 / 退出；启动不自动打开浏览器
- 新增 `webserver.py`（路由与静态托管，HTTP + JSON 轮询，无 WebSocket / SSE）与 `webservice.py`（搜索 / 播放 / 下载任务 / 日志缓冲等业务服务层）
- 新增 `cfgstore.py`：默认配置、读写、字段校正与导入导出，各模块共用同一份 `config.json`；敏感字段不再下发前端，仅以布尔位表示是否已配置
- 新增 `web/` 前端（`index.html` / `app.css` / `app.js`），无构建工具，由本地服务直接托管
- 双界面模式：**下载模式**（保留浮动迷你播放器：左上歌曲信息、右歌词、底部居中控制，标题过长以传送带滚动）与 **播放器模式**（左半屏封面与控制、右半屏跟随高亮并自动居中的滚动歌词）
- 左右两个独立悬浮岛：左缘唤出「播放列表」、右缘唤出「下载任务」，点击别处自动隐藏，岛头可拖动并记忆位置；播放列表条目支持右键菜单与悬停小 × 移除，下载任务岛支持暂停 / 继续 / 取消 / 重试
- 搜索框自动识别输入类型（文本走搜索、歌单 ID / 链接直接加载、单曲链接直接定位），右侧爱心按钮一键载入「我喜欢的音乐」，搜索 / 歌单 / 我的音乐共用同一表格与同一搜索框，新结果直接覆盖
- 列表列宽可拖动调整：序号列按当前最大序号位数自适应，其余列默认按内容长短分配，缩小极限为默认宽度的一半、放大不设限；切换列表来源后统一刷新列表相关控件状态
- 设置页固定尺寸、内容独立滚动（切换分类窗口不再跳动），分为 音乐 / 用户 / 系统 / 日志 四个分类；密钥按音源分组配置（网易云 weapi 密钥 与 QQ 音乐凭证可分别设置）
- 运行日志收进设置页并支持级别过滤与清空（原先独立入口与下载任务功能重复）
- 列表可导出 CSV / M3U / TXT；配置支持整份导入 / 导出

- 列表列头排序改为三态循环：升序 → 降序 → 还原原始载入顺序（表头箭头随之切换 / 消失）
- 列表内关键字过滤：搜索页 / 歌单页新增过滤框，输入即按 歌名 / 歌手 / 专辑 实时过滤，右侧「清空」一键复原（220ms 防抖，大列表不卡顿）
- 列表统计：过滤框右侧显示「当前首数 · 总时长 · 总大小≈」，随音质切换与列表变化同步刷新
- 命名模板新增 `{index}` 占位符，可生成带序号的连续文件名
- 新增「文件组织」设置：可在下载目录下按 歌手 / 专辑 / 歌手+专辑 分文件夹存放
- 新增「按任务分文件夹」：每次下载任务在下载目录下新建 `任务 日期-时间` 子目录，可与歌手 / 专辑分文件夹叠加；设置页可开关，默认关闭
- 音频标签可嵌入歌词：下载选项窗新增「嵌入歌词到标签」，MP3 / FLAC / M4A 分别写入对应歌词标签
- 下载完成通知：设置页新增「弹出完成通知」，下载结束后提示音 + 右下角浮窗 + 任务栏闪烁
- 歌单入口支持粘贴单曲链接：识别网易云 `/song?id=` 与 QQ `/songDetail/` 单曲链接并直接追加到列表（音源不一致时提示先切换音源）

**下载完成后动作**
- 新增统一设置「下载完成后」：无 / 消息 / 弹窗 / 打开目录 / 关机，保存在 `config.json`，可在设置页修改
- 每次提交下载时可在下载选项窗里单独改选「完成后」，只对当前任务生效，不写回全局默认
- 「消息」为 Windows 托盘气泡通知（无托盘时退化为弹窗）；「弹窗」为基于后台窗口的右下角提示，提供「打开目录」「好的」
- 完成动作由后端执行：浏览器关闭后仍会生效；关机默认延迟 60 秒（可用 `shutdown /a` 取消）
- 移除 SMTP / 邮件提醒相关代码与配置项，旧配置中的邮箱字段在读取时自动丢弃
- 旧配置的「完成后打开目录」开关在读取时自动迁移为对应的完成动作

**状态栏歌词**
- 播放时最下方状态栏左侧显示当前歌词，并随歌词长度把下载进度条向右「顶」开，歌词变短后弹性伸回
- 歌词宽度上限为窗口宽度的 60%（设置 → 音乐 可调），超出上限时按传送带方式滚动，当前唱到的字保持在视野约 70% 处
- 进度条右侧固定预留「| 99.9%」数字进度位；缩短的只是可视填充，实际进度比例不变
- 下载任务完成后点击数字进度可清空进度条
- 该效果可在设置中关闭；无播放时歌词区自动隐藏

### 改进

**网络与会话**
- 匿名模式下账号校验不再重复发起匿名注册：依据会话中是否已有 `deviceId` 判断，退出登录清空 cookie 后可自动重新注册
- 下载器统一复用连接池并在批次结束后释放（无会话音源走内置会话），不再每首新建连接或遗留未关闭的会话
- QQ 音乐异步调用 `.result()` 增加超时，避免底层请求异常时永久占用后台工作线程
- 已登录时账号校验不再重复拉取「我喜欢的音乐」集合，同一音源仅拉取一次

### 变更

**Web 版界面**
- 爱心按钮并入查询框左侧拨码开关组，移除右侧独立爱心按钮
- 查询栏的「查询中 / 已加载 N 首，滚动到底继续加载」等状态迁移到列表上方信息条左侧，并移除静态提示「双击播放 · 右键更多操作 · 拖动表头调列宽」
- 移除右侧悬浮岛：下载任务改为顶栏按钮打开的独立窗口，可拖动、可拉伸、列表可滚动
- 移除下载模式的浮动迷你播放器：改为搜索框右侧的「当前音乐封面」按钮，点击弹出独立播放器窗口（右侧顶部滑块切换 歌词 / 播放列表 / 歌曲信息）
- 播放列表改为仅由用户显式添加：双击听歌加入并播放、全部播放整批追加、右键下一首播放 / 添加到播放列表，按歌曲标识去重；播放列表支持拉伸与滚动条
- 修复启动时设置项空引用导致 `boot()` 中断、账号登录状态未刷新的问题（页面显示「未登录」）
- 修复加载「我喜欢的音乐」后切换搜索 / 歌单模式时爱心高亮未清除的问题
- 「下载完成后」默认动作移入设置页「音乐」分类，与下载选项放在一起，便于查找
- 无歌曲播放时，封面按钮与播放器封面改用用户头像
- 双击启动时隐藏本进程独占的控制台窗口，任务栏只保留桌面状态窗口（从已有终端启动时不受影响）

**架构**
- 列表数据层重构：以「全部歌曲」为唯一基准，排序与过滤只作用于显示层并统一经重建渲染；勾选 / 喜欢状态改由歌曲标识集合派生，过滤 / 排序重建行号后状态不再丢失
- 网易云 / QQ 两个扫码轮询 worker 合并共用轮询骨架（`ServiceHub._poll_qr`），去除重复的超时与异常处理
- 网易云 `song_url` / `_weapi` 支持注入会话，新增 `clone_session()` 供上层并发请求使用，避免并发共享 Session

## [1.0.2] - 2026-10-17

### 新增

**密钥可配置**
- 设置页新增「高级密钥」对话框，可在程序内查看 / 修改 / 校验 / 恢复默认 weapi 加密密钥（`weapi_keys`），保存后立即生效
- 密钥合法性校验：key1 / iv 必须 16 字节、pub_key / modulus 必须为合法十六进制、modulus 不超过 1024 位；非法输入弹窗提示且不写入配置
- 保存密钥时仅替换已缓存网易云实例的加密器，**不重建实例**，登录态与匿名 token 不受影响
- API 凭证（`credentials`）页支持查看 / 编辑 / 保存；该组凭证当前不参与任何请求，仅作留档

**设置**
- 新增「下载完成后自动打开下载目录」选项

### 性能

- 列表滚动预加载由 O(n) 降为 O(1)：按已载入歌曲数判断，不再每次滚动都遍历全部行
- 表头排序改为「按歌曲排序后整表重建」：保留各行勾选 / 喜欢状态，Tk 调用次数较原「逐行移动 + 逐行改写序号」减少约三分之一；「序号」列排序仍可按原始载入顺序还原
- 「喜欢」「大小」列刷新与勾选切换改为单格写入（`Treeview.set`），省去读改写整行
- 已选计数改为增量维护，勾选 / 全选 / 清空不再全表统计
- 下载进度聚合（`ProgressHub`）改为增量累计字节与完成度，上报与采样不再遍历全部格子
- 网易云歌单详情分批请求改为限并发（最多 3 路，各批独立会话），长歌单加载更快；任一批失败自动回退串行

### 变更

**架构**
- 新增 `services.py` 后台服务层（`ServiceHub`）：把线程调度、消息投递与全部 worker 从界面层下沉，界面只负责渲染与事件分派
- 主线程消息分派改为 tag → 处理函数查表，替代 17 段 if/elif 链
- 抽出列表列索引常量（`COLUMNS` / `COL`），替换散落的 `values[0..8]` 与 `'#1'` 硬编码
- 树数据字典改用控件对象作键，不再用 `str(tree)`
- 清理 `models.py` 中零引用的 `LEVELS` / `LEVEL_LABELS` / `LABEL_LEVELS` / `LABEL_LEVELS_BY_SOURCE`
- 网易云 weapi 加密密钥不再硬编码：`encrypt.py` 提供 `WEApiKeys` / `WEApiCipher`，由 `config.json` 的 `weapi_keys` 注入（缺失时回退内置默认值）

**配置**
- `config.json` 新增 `weapi_keys` 与 `open_dir_after_download` 字段

## [1.0.0] - 2026-10-14

首个公开发布版本。

### 新增

**音源**
- 网易云音乐：关键词搜索（分页加载）、歌单下载、Cookie 登录、扫码登录、音质选择
- QQ 音乐：搜索、取址、歌词、歌单、扫码登录与 Cookie 登录

**搜索与歌单**
- 搜索结果不再限于 50 条：滚动到列表底部自动预加载下一页，另可手动「加载更多」
- 「我的歌单」窗口，浏览自己创建与收藏的歌单
- 一键获取「我喜欢的音乐」到列表

**列表交互**
- 多选复选框、全选 / 清空勾选、实时已选计数
- 点击表头排序、一键去重
- 右键快速操作菜单
- 双击打开歌曲详情：标签信息、封面预览、音质探测
- 「喜欢」列标记已在「我喜欢的音乐」中的歌曲

**下载**
- 下载选项弹窗（歌词 / 标签 / 封面 / 跳过已存在），确认后记忆为下次默认

**界面**
- 顶部登录信息展示：头像、昵称、ID、VIP 类型
- 列表「大小≈」列按当前音质预估文件大小
- 修复编码格式下拉框取值错误（KeyError）
- 修复歌单链接解析误抓域名中的数字导致加载失败
